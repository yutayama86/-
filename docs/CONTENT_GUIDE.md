# 取材・コンテンツ制作ガイド

実際の更新手順と入力例は [`UPDATE_GUIDE.md`](./UPDATE_GUIDE.md) を参照してください。この文書は編集品質の基準を定めます。

## 記事の原則

1. 現地取材の有無を明示する。
2. 事実、本人の発言、編集部の印象を混同しない。
3. 住所・営業時間・価格・予約先は公式情報と照合する。
4. 招待、商品提供、費用負担、契約関係を開示する。
5. 写真・氏名・発言の公開許諾を確認する。
6. 誤りは訂正し、重要な変更は履歴に残す。

## タイトルと説明文

- タイトルは内容に忠実にし、地名・人・営みが自然に分かる言葉を選ぶ。
- 説明文は、誰を訪ね、何を確かめ、何が分かる記事なのかを70〜120文字程度で書く。
- 数字や強い言葉をクリック目的だけで足さない。

## 本文の基本構成

1. この記事で確認できたこと
2. 現地の背景と人
3. 具体的な体験・仕事・営み
4. 本人の言葉（意味を変えず、許諾の範囲で）
5. 編集部の観察と訪問前の注意
6. 出典・取材日・更新履歴

## 公開条件

- 作業中は `draft: true`
- 事実、権利、関係性の開示を確認後に `reviewed: true`
- 公開時に `draft: false`
- Partner / PR は `disclosureNote` 必須
- 公開前に `npm run check`

テンプレートは記事用 [`src/content/articles/_template.md`](../src/content/articles/_template.md) と場所用 [`src/content/places/_template.md`](../src/content/places/_template.md) を使用してください。
