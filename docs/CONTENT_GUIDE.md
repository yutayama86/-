# 取材記事・店舗LP 制作ガイド（編集部用）

イバトコの記事は「行った人の熱量」が命です。同時に、検索とSNSから“発見される”設計も欠かせません。この2つを両立させるためのチェックリストです。

---

## 🖊 記事を1本つくる流れ

1. `src/content/articles/<ジャンル>/` に [`_template.md`](../src/content/articles/_template.md) をコピー
   （またはDecap CMS `/admin/` の「よみもの」→「新規」）
2. ファイル名は英数字ハイフン（例 `mito-cafe-hoge.md`）→ これがURLになります
3. フロントマターを埋める → 本文を書く → `draft: false` で公開

## ✅ 公開前チェックリスト

**タイトル（title）**
- [ ] 32文字前後。**地名 or 数字**が入っている（例「行列8分待ちでも…つくば『かぜ』」）
- [ ] 検索語（ラーメン/サウナ 等の**ジャンル語**）が含まれる

**説明（description）**
- [ ] 80〜120文字。「誰の・どんな課題に・何を」が1文でわかる
- [ ] 地名＋ジャンル語が入っている

**本文**
- [ ] リードで“結論の熱量”を先に出している
- [ ] 見出し（`##`）が2〜4個。五感の描写がある
- [ ] 取材班の「ひとこと（`>` 引用）」が1つある
- [ ] 「こんな人におすすめ」で読者の次の一歩を後押ししている

**設定**
- [ ] `category` が正しい
- [ ] `area`（市町村）を入れた（ローカルSEOに効く）
- [ ] `tags` を3〜6個
- [ ] 取材したお店があるなら `place:` に店舗IDを設定 → 記事末尾に**予約導線**が自動で出る
- [ ] `cover`（アイキャッチ）を設定（無くてもデザイン枠が出ます）

> 💡 `cover` を入れなくても、記事ごとの**OGP画像（SNSシェア画像）は自動生成**されます。
> タイトル・ジャンルが入ったブランド画像がSNSに表示されます。

---

## 🏪 店舗LP（ペライチ）をつくる

1. [`src/content/places/_template.md`](../src/content/places/_template.md) をコピー（またはCMSの「掲載店舗」）
2. ファイル名＝店舗ID（例 `mito-cafe-hoge`）→ URLは `/place/mito-cafe-hoge/`
3. **`recommend`（取材班コメント）** と **`menu`** はLPの成約率に直結。必ず埋める
4. 記事側の `place:` に同じ店舗IDを設定すると、記事⇄LPが相互リンクされます

**掲載プラン（plan）** … `free`（無料）/ `listing`（ライト月額）/ `partner`（パートナー）。営業状況に合わせて。

---

## 🔁 集客→予約の導線（この設計が“稼ぐ”核）

```
記事（熱量で惹きつける）
  └→ 記事末尾の店舗カード
        └→ /place/[店舗ID]/（比較検討・推薦・メニュー）
              └→［予約・お問い合わせ］ボタン
                    └→ /reserve/（店舗プリセット済みフォーム）
```

記事に必ず `place:` を紐づけることで、この導線が途切れず繋がります。
