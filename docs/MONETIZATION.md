## 2. 提携を有効にするまで（本人の作業）

コードからはできない。申請・審査・規約の同意・口座登録は本人の操作が必要。

| 提供元 | 使うASP | 状況（2026-09-17） | 備考 |
|---|---|---|---|
| 楽天トラベル | **楽天アフィリエイト** | **リンク設置済み**（大洗／水戸の2本） | 提携審査なし。バリューコマースでは提携しない |
| じゃらんnet | **A8.net** | **提携承認済み**（提携日 2026/09/16）。リンク未作成 | 「商品リンク作成」でエリアページ2本。公開後に広告掲載URLを提出 |
| akippa | A8.net（候補） | 未申請 | 見つからなければ公式リンクのまま |

**同じ広告主を2つのASPで提携しない。** 1記事のなかで別々のASPのリンクが混ざると、
成果の集計先と規約の適用先が分からなくなる。バリューコマースは媒体登録のみで、**提携はしない**
（じゃらんはA8が先に承認されたため。VCは即時提携・MyLinkが使える一方、サイト審査が終わっていない）。

**確認すること**（申請前に各ASP・プログラムの規約で）

- 掲載できる文言・画像（ロゴや施設写真の利用可否）
- 表記義務（「広告」「PR」「アフィリエイトリンクを含む」などの書き方と位置）
- 禁止事項（順位の保証、価格の自動転載、クッキーの扱いなど）
- 報酬条件（成果地点、承認までの期間、否認条件、最低支払額）

**承認されたら**

1. ASPの管理画面で生成したリンクを、`src/data/affiliates.ts` の `affiliateLinks` に
   「記事に書いてある元URL → 生成された広告リンク」の形で貼る（**リンクを組み立て直さない**）
2. 該当提供元を `status: 'active'` にする（`'active'` のときだけ広告リンクになり、広告表示が出る）
3. `npm run verify` を通す → 公開 → 実際のリンク先と計測を1件ずつ確認する
4. この文書の冒頭の表を更新する

**LinkSwitch（サイト内の通常リンクを自動で広告リンクへ変える仕組み）は使わない。**
どのリンクが広告になったかをこちらで把握できず、「広告」表示と `rel="sponsored"` を
付ける対象が実際の挙動とずれるため。リンクは MyLink で1本ずつ作る。

**やらないこと**：提携IDや報酬条件を推測で書くこと。未提携のまま「広告」と表示すること。

**掲載時の指定**

- **ページ上部に「#アフィリエイト広告」を入れるなど、アフィリエイト広告掲載である旨を記載する**
  → 記事冒頭の広告表示に `#アフィリエイト広告` を含める実装にした
- 景表法違反となる広告表示・景品提供は禁止。著しく優良・有利と誤認させる表示をしない
- 提携したことを事前連絡なしにプレスリリースしない
- リスティング禁止ワード：サイト名・会社名・ブランド名・商品名などの商標を含む複合ワード
  （ひらがな・カタカナ・ローマ字・打ち間違いを含む）。違反は提携解除および注文拒否
- **成果が発生している広告掲載ページを極力削除しない**
  → 記事を消す・URLを変える判断をする前に、そのページに広告リンクがあるかを確認する

**いまサイトが審査中であることの扱い**

バリューコマースの画面には「審査中および審査で非承認となった場合、広告は正しく表示されません」とある。
広告コードを先に貼っておけば審査完了後に自動で配信が始まる仕組みだが、**審査中は読者のクリックが
正しく飛ばない可能性がある**。そのため、生成リンクを受け取っても `src/data/affiliates.ts` の
`status` は `'applied'` のままにし、**リンクは通常の公式リンクとして動かす**。
サイト審査の完了を確認してから `'active'` に切り替える（切り替えは1行の変更で済む）。

**実装・運用への影響**

1. リンク先は**宿・ホテル予約のページ**に限る（現在は `https://www.jalan.net/100000/LRG_101400/` などのエリア一覧）。
   遊び・体験や航空券のページへリンクしても報酬にならないため、宿泊以外の導線に流用しない。
2. スマートフォンでじゃらんアプリが入っていると、リンクからアプリへ飛んで**成果にならないことがある**。
   クリックが出ているのに成果が0のときは、まずこれを疑う（読者にアプリを避けるよう促すことはしない）。
3. 「宿泊した月の翌月」にカウントされるため、**クリックから報酬確定まで数か月かかる**。
   `docs/records/affiliate-results.csv` では成果発生・否認・確定報酬・入金を別の列で記録し、発生時点を収益として数えない。
4. 記事側では、割引・最安・お得といった**価格の断定を書かない**（プラン内容と価格は変動するため）。
5. **生成された広告リンクを書き換えない。** 商品リンクには計測用のパラメータが付くため、
   `affiliates.ts` では「元URL → 生成された広告リンク」の対応表で持つ（URLを組み立て直さない）。
   飛び先は `https://www.jalan.net/` 内に限ると指定されている。
6. **サイト名・ページタイトル・本文で、じゃらんnetやリクルートが運営していると誤解させる書き方をしない。**
   リンクの文言は「大洗・ひたちなかの宿を探す（じゃらんnet）」のように、探す先として示す。
7. **広告表示は、記事の上部（ファーストビュー）にも出す。** 広告リンクを含むページでは、
   記事冒頭に「この記事にはアフィリエイト広告を含みます。」を自動で表示する（`src/pages/news/[slug].astro`、`src/pages/events/[slug].astro`）。
   記事末のブロックにも広告表示を出す。表示がないと、提携が承認されない・解除される可能性があると案内されている。
8. 景品表示法に触れる表現（実際のサービスより著しく優良・有利と誤解させる表示）をしない。
9. 提携したこと自体を、事前連絡なしにプレスリリース等で公表しない。
10. **公開後、A8の「広告掲載URL管理」から、広告を載せたページのURLを提出する**（本人の作業）。

## 4. うまくいかないときに見る順番

1. **露出が少ない**（表示回数が伸びない）→ 集客の問題。検索クエリと掲載順位を見る
2. **読まれているのに押されない**（表示はあるがクリックが少ない）→ 案内の問題。置き場所・文言・選択肢の数を見直す
3. **押されているのに成果が出ない**（クリックはあるが成果0）→ 商品との相性、計測、承認状況を見る（提携前ならまず提携）

初期の収益が確認できるまでは、会員機能・決済・高度な検索・管理画面の追加より、この導線の改善を優先する。
