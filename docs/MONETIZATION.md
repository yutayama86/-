`link_provider` `link_kind` `partner_status` `link_page_type`
（`cta_type` などは 2026-09-15 に登録済み。手順は `docs/GA4_MEASUREMENT.md`）

## 2. 提携を有効にするまで（本人の作業）

コードからはできない。申請・審査・規約の同意・口座登録は本人の操作が必要。

| 提供元 | 想定する提携先 | 申請時に必要なもの | 備考 |
|---|---|---|---|
| 楽天トラベル | 楽天アフィリエイト／バリューコマース | サイトURL、運営者情報、楽天ID（またはASPアカウント） | 媒体審査あり |
| じゃらんnet | リクルートのアフィリエイト／バリューコマース | サイトURL、運営者情報、ASPアカウント、口座情報 | 媒体審査あり |
| akippa | A8.net／バリューコマース | サイトURL、運営者情報、ASPアカウント、口座情報 | プログラム提携申請が別途必要 |

**確認すること**（申請前に各ASP・プログラムの規約で）

- 掲載できる文言・画像（ロゴや施設写真の利用可否）
- 表記義務（「広告」「PR」「アフィリエイトリンクを含む」などの書き方と位置）
- 禁止事項（順位の保証、価格の自動転載、クッキーの扱いなど）
- 報酬条件（成果地点、承認までの期間、否認条件、最低支払額）

**承認されたら**

1. `src/data/affiliates.ts` の該当提供元を `status: 'active'` にする
2. `affiliateUrl` に、通常URLを広告リンクへ変換する関数を書く（IDは環境変数か、このファイルに直接）
3. `npm run verify` を通す → 公開 → 実際のリンク先と計測を1件ずつ確認する
4. この文書の冒頭の表を更新する

**やらないこと**：提携IDや報酬条件を推測で書くこと。未提携のまま「広告」と表示すること。

## 4. うまくいかないときに見る順番

1. **露出が少ない**（表示回数が伸びない）→ 集客の問題。検索クエリと掲載順位を見る
2. **読まれているのに押されない**（表示はあるがクリックが少ない）→ 案内の問題。置き場所・文言・選択肢の数を見直す
3. **押されているのに成果が出ない**（クリックはあるが成果0）→ 商品との相性、計測、承認状況を見る（提携前ならまず提携）

初期の収益が確認できるまでは、会員機能・決済・高度な検索・管理画面の追加より、この導線の改善を優先する。
