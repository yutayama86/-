# 公開前監査票

更新日: 2026-08-01

この文書は、イバトコを公開・更新するときの最終確認票です。法的判断を保証するものではありません。判断に迷う広告表示、比較表示、権利処理、個人情報の取り扱いは専門家へ確認してください。

## 現在の判定

- 型検査・静的ビルド: 合格
- 内部リンク: 欠落なし
- 依存パッケージ監査: 既知の脆弱性 0 件
- 画像代替テキスト・主要見出し・横スクロール: 主要ページで問題なし
- canonical、OG、robots、構造化データ: 実装済み
- 未確認コンテンツの公開防止: `draft: false` と `reviewed: true` の両方を必須化
- Partner / PR: 関係性の説明文を必須化
- 根拠のない順位・最上級表現: 公開用コピーから撤去

## 公開前に運営者が確認すること

### 1. 事実と根拠

- 店名、住所、営業時間、価格、予約方法を公式情報と照合した
- 「日本一」「県内最大」「人気No.1」「最安」などを使う場合、調査主体・対象・期間・方法または公的出典と統計年度を同じ画面で示した
- 感想は事実と混ぜず、「編集部が訪問した際の印象」など主体と時点を明記した
- 価格や営業情報には確認日を付けた

### 2. 広告・提供・招待

- 対価、商品提供、招待、交通費負担、継続契約など、表示に影響し得る関係を把握した
- 編集記事、Partner、PRの区分を正しく設定した
- Partner / PRでは、読者が関係性を理解できる具体的な説明を入れた
- 広告主の指示で作った表示を、第三者の自発的な感想のように見せていない

### 3. 権利とプライバシー

- 写真・文章・ロゴ・地図素材の利用許諾またはライセンスを記録した
- 人物が識別できる写真は掲載同意を得た
- 店内、私有地、未成年、車両番号などへの配慮を確認した
- 引用は必要最小限で、引用元を明示した

### 4. 品質とSEO

- タイトルと説明文がページ固有で、内容と一致している
- H1は原則1つで、見出し順が自然である
- 画像に内容が分かる代替テキストがある。装飾画像は空の代替テキストである
- 公式URL、関連記事、エリア・テーマ導線が正しい
- 架空の人物、体験、口コミ、件数を補っていない
- 公開後にスマートフォンで読みやすさとリンクを確認した

## 本番接続前の実機確認

次の項目はコードだけでは確定できません。

- 問い合わせフォームが運営者へ届き、自動返信と個人情報の扱いが意図どおりか
- アクセス解析・Cookieがプライバシーポリシーの記載と一致するか
- 運営者名、住所、連絡先、各種SNS URLが正式情報か
- 実写真・実記事の権利台帳と取材同意が揃っているか
- 正式ロゴの商標・類似調査が完了しているか

## 更新方法

日常の更新と細かな文言変更は `docs/UPDATE_GUIDE.md` を参照してください。公開前は `npm run check` を実行し、この監査票を上から確認します。
