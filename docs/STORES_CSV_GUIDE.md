# 店舗の無料一括掲載ガイド（stores.csv）

無料掲載の店舗は `src/data/stores.csv` に**1行1店舗**で追記するだけで、ビルド時に
店舗ページ（`/place/<slug>/`）が自動生成され、ディレクトリ・市町村ページ・
地名×ジャンルまとめにも自動で反映されます。＝**供給エンジン**の入口。

作り込みの取材記事つき店舗は従来どおり `src/content/places/*.md`（Markdown）で管理します。
両者は同じ `/place/<slug>/` に共存し、同じ slug なら Markdown 側を優先します。

## 追加の手順

1. `src/data/stores.csv` を表計算ソフト（Excel / Googleスプレッドシート / Numbers）で開く。
2. 行を追記する。**slug と name と category と area と tagline は必須**。
3. CSV（UTF-8, カンマ区切り）で保存して commit → push。Cloudflare が自動デプロイ。

> Googleスプレッドシートで管理→「ファイル > ダウンロード > CSV」でも運用可。将来は D1（DB）へ移行予定。

## 列の仕様

| 列 | 必須 | 例 | 説明 |
|---|---|---|---|
| `slug` | ✅ | `mito-cafe-hitohira` | URLになる半角英数・ハイフン。**全店舗で一意**。`市町村-業態-店名` を推奨。 |
| `name` | ✅ | `珈琲 ひとひら` | 店名 |
| `kana` | | `HITOHIRA` | 読み・英字表記（見出し下に小さく表示） |
| `category` | ✅ | `eat` | `eat`/`life`/`sauna-play`/`beauty`/`stay`/`company` のいずれか |
| `tagline` | ✅ | `水戸の路地裏、静かな一杯。` | 一言キャッチ（一覧・ヒーローに出る） |
| `description` | | `水戸市の…喫茶店。` | 説明文。空なら「エリア＋店名」で自動生成 |
| `area` | ✅ | `水戸市` | 市町村名（「水戸市」等）。これで地図・エリアページに紐づく |
| `address` | | `茨城県水戸市泉町X-XX` | 住所 |
| `access` | | `水戸駅北口から徒歩10分` | アクセス |
| `hours` | | `10:00–19:00` | 営業時間 |
| `holiday` | | `水曜` | 定休日 |
| `tel` | | `029-XXX-XXXX` | 電話 |
| `budget` | | `¥500–1200` | 予算 |
| `features` | | `自家焙煎｜Wi-Fiあり｜駐車場あり` | 特徴タグ。**全角「｜」区切り**（半角`|`も可）。絞り込みに使う |
| `website` | | `https://…` | 公式サイト（URL形式） |
| `instagram` | | `https://instagram.com/…` | Instagram |
| `map` | | `https://maps.google.com/…` | 地図リンク（URL形式） |
| `plan` | | `free` | `free`（無料）/`official`（公式）等。既定 `free` |
| `publishedAt` | | `2026-07-20` | 掲載日（`YYYY-MM-DD`）。空なら既定日 |

### 注意

- 値に**カンマを含む**ときは、そのセルをダブルクオートで囲む：`"茨城県水戸市南町X-X-X, 2F"`。
- `features` の区切りだけは**カンマではなく `｜`**。カンマは列区切りとぶつかるため。
- 空セルは「未設定」。無理に埋めなくてOK（住所や電話は後から追記できる）。
- `cover`（写真）列は現状スキーマ非対応（作り込み店舗の md 側で運用）。無料掲載は
  写真なしの上品なフォールバック表示になる。写真を増やすのは「公式店舗」化の動機付け。

## 特徴タグ（features）の推奨語彙

絞り込みが散らからないよう、なるべく下記の言い回しに揃える（2件以上で絞り込みチップに出る）。

- **共通**：`駐車場あり` `個室あり` `カード可` `予約可` `テイクアウト可` `お一人様歓迎` `キッズ歓迎` `Wi-Fiあり` `電源あり`
- **グルメ**：`ランチあり` `行列店` `無化調` `自家製麺` `和え玉あり` `自家焙煎` `自家製酵母`
- **あそび・サウナ**：`セルフロウリュ` `外気浴` `オーシャンビュー` `タオルレンタル` `ファミリー向け` `レンタルあり`
- **ビューティ**：`完全予約制` `女性専用` `駐車場あり`
- **泊まる**：`温泉` `露天風呂` `オーシャンビュー` `送迎あり` `磯料理`
- **暮らし/企業**：`朝どれ` `地方発送可` `作家もの` `企画展あり`
